### ③ 软硬件划分依据与接口设计

- **划分依据**：PL 做"每像素一次操作"的带宽型任务；PS 做"需要循环迭代与权重"的算力型任务

> 素材：`../docs/architecture-contract.md` §三（接口契约）、§五（决策记录）。
